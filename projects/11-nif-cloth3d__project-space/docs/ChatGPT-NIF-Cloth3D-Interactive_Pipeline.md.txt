## Step 2: Blender-Based Pipeline

We construct a Blender Python pipeline to **simulate cloth**, **export meshes**, and **generate SDF voxel grids**. First, we define a Blender scene with a cloth object, wind force, and pinned vertices. The script bakes the simulation and exports each frame as a mesh. After running the above Blender script, we get OBJ files and a JSON file. Next, we convert each mesh into an SDF voxel grid. Here is a simple Python conversion using NumPy and a mesh-distance approach:

```python
# convert_mesh_to_sdf.py
import numpy as np
import trimesh
import json

def mesh_to_sdf(mesh, grid_size=64, padding=0.1):
    """
    Convert a trimesh mesh to a voxel SDF (signed distance) grid.
    """
    # Compute bounding box and extend it
    bounds = mesh.bounds
    min_corner = bounds[0] - padding
    max_corner = bounds[1] + padding
    # Create uniform grid
    xs = np.linspace(min_corner[0], max_corner[0], grid_size)
    ys = np.linspace(min_corner[1], max_corner[1], grid_size)
    zs = np.linspace(min_corner[2], max_corner[2], grid_size)
    xv, yv, zv = np.meshgrid(xs, ys, zs, indexing='ij')
    pts = np.stack([xv, yv, zv], axis=-1).reshape(-1,3)
    # Compute signed distances (positive outside, negative inside)
    # Here we approximate SDF by unsigned distance (Trimesh only gives unsigned)
    dist = mesh.nearest.signed_distance(pts)
    sdf = dist.reshape(grid_size, grid_size, grid_size)
    return sdf

# Load metadata
with open("/tmp/cloth_metadata.json", "r") as f:
    meta = json.load(f)

# Process each exported mesh
sdf_data = []
for obj_path in output_meshes:
    mesh = trimesh.load(obj_path)
    sdf_grid = mesh_to_sdf(mesh, grid_size=64, padding=0.2)
    sdf_data.append(sdf_grid.astype(np.float32))
# Save all SDFs (e.g., as npz or other format)
np.savez_compressed("/tmp/cloth_sdf_data.npz", *sdf_data, wind=meta["wind_strength"])
```

This pipeline yields a set of voxel-SDF tensors and simulation metadata for each frame. The SDF can be used for collision checks or as inputs to our neural model. The JSON contains forces and pin indices used in the simulation for conditional inputs.

## Step 3: Sine-Activated MLP

We implement a sine-activated multi-layer perceptron (MLP) in PyTorch. The MLP maps 6D inputs *(x, y, z, t, force\_vector (3D), material\_id)* to a deformation or velocity output. We use sinusoidal activations (`sin`) to capture high-frequency detail (following the “SIREN” approach). We also define physics-informed loss terms:

- **Stretch loss**: penalizes deviation from inextensibility. For cloth, this can be approximated as maintaining geodesic distances. Mathematically, $L\_{\text{stretch}} = \sum\_{(i,j)\in E} (||u\_i - u\_j|| - d\_{ij})^2$, where $d\_{ij}$ is rest length.
- **Bend loss**: enforces smooth curvature. One can use second-derivative penalties or Laplacian on the surface: $L\_{\text{bend}} = \sum\_i ||\Delta u\_i||^2$.
- **Momentum (inertia) loss**: enforces dynamic consistency. Using Newton’s law, $\rho \ddot{u} - \nabla \cdot \sigma - f = 0$. We minimize residual $L\_{\text{momentum}} = ||\rho \ddot{u} - f\_{\text{net}}||^2$, where $f\_{\text{net}}$ includes applied forces (e.g. wind, gravity) and internal elastic forces.

We assume a simple mass-spring discretization for demonstration. The code below defines the network and a training loop with these losses:

```python
# sine_mlp_cloth.py
import torch
import torch.nn as nn
import numpy as np

class SineLayer(nn.Module):
    def __init__(self, in_features, out_features, w0=30.0):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)
        self.w0 = w0
        # SIREN initialization: higher variance for first layer
        self.linear.weight.data.uniform_(-1/np.sqrt(in_features), 1/np.sqrt(in_features))
        self.linear.bias.data.zero_()
    def forward(self, x):
        return torch.sin(self.w0 * self.linear(x))

class SineMLP(nn.Module):
    def __init__(self, in_dim=8, hidden_dim=128, out_dim=3, w0=30.0, n_layers=4):
        super().__init__()
        layers = [SineLayer(in_dim, hidden_dim, w0)]
        for _ in range(n_layers - 1):
            layers.append(SineLayer(hidden_dim, hidden_dim, w0))
        self.net = nn.Sequential(*layers)
        self.final = nn.Linear(hidden_dim, out_dim)
    def forward(self, x):
        out = self.net(x)
        return self.final(out)

# Example: assume cloth mesh with N vertices
N = 1000  # number of vertices
# Rest positions and adjacency (for losses)
rest_pos = torch.randn(N, 3)  # placeholder rest state
edges = [(i, i+1) for i in range(N-1)]  # placeholder connectivity
material_ids = torch.randint(0, 5, (N, 1))  # one of 5 materials

model = SineMLP(in_dim=3+1+3+1, hidden_dim=256, out_dim=3)  # (xyz + t + force3 + matID)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)

def compute_physics_loss(pred_disp, inputs):
    """
    Compute physics-informed losses given predicted displacements and inputs.
    """
    loss = 0.0
    # Stretch: penalize change in length from rest
    for (i, j) in edges:
        # current positions = rest + predicted displacement
        u_i = rest_pos[i] + pred_disp[i]
        u_j = rest_pos[j] + pred_disp[j]
        rest_len = torch.norm(rest_pos[i] - rest_pos[j])
        cur_len = torch.norm(u_i - u_j)
        loss += (cur_len - rest_len)**2
    # Bend: second-derivative (Laplacian) approximation
    for i in range(1, N-1):
        u_prev = rest_pos[i-1] + pred_disp[i-1]
        u_curr = rest_pos[i] + pred_disp[i]
        u_next = rest_pos[i+1] + pred_disp[i+1]
        lap = u_prev - 2*u_curr + u_next
        loss += torch.sum(lap**2)
    # Momentum: approximate with finite differences (placeholder)
    # If t input changes, compute acceleration
    # Here we assume predicted output is displacement; then velocity = d/dt, but we skip actual time integration.
    # For demonstration, add small damping loss
    loss += 0.01 * torch.sum(pred_disp**2)
    return loss

# Training loop (simplified)
for epoch in range(100):
    model.train()
    optimizer.zero_grad()
    # Prepare input tensor: [ (x,y,z), t, (fx,fy,fz), materialID ]
    # For simplicity, use zeros or random as example
    xyz = torch.randn(N, 3)
    t = torch.full((N,1), epoch / 100.0)  # normalized time
    force = torch.randn(N, 3) * 0.1  # external forces per vertex
    mat = torch.nn.functional.one_hot(material_ids.squeeze(), num_classes=5).float()
    inp = torch.cat([xyz, t, force, mat], dim=1)
    pred_disp = model(inp)  # shape (N,3)
    loss_phys = compute_physics_loss(pred_disp, inp)
    loss = loss_phys
    loss.backward()
    optimizer.step()
    if epoch % 10 == 0:
        print(f"Epoch {epoch}, Loss: {loss.item():.4f}")
```

In this example, the `SineMLP` uses sinusoidal activation to model complex deformations. The `compute_physics_loss` function encodes stretch (length preservation) and bend smoothness. (In practice, one would use a realistic mesh adjacency and time integration to compute true momentum residuals.) The training loop feeds vertex positions `(x,y,z)`, time `t`, an external force vector, and a one-hot material ID into the network, and backpropagates the physics loss. This enforces learned predictions that respect cloth elasticity and dynamic consistency.

## Step 4: Real-Time Optimization

To prepare for real-time interaction on an RTX 4090, we enhance the model with caching, mixed precision, and potential CUDA kernels. Here are key modifications:

1. **Voxel-hash cache**: We create a hash-grid cache of SDF values (like Instant-NGP). For each query, if nearby voxels are cached, we skip full network eval. (Below we outline a cache lookup stub.)
2. **FP16 support**: Enable half-precision to speed up inference (`torch.cuda.amp`).
3. **Tiny CUDA kernels**: For bottleneck ops (e.g. SDF sampling), ideally we’d write custom CUDA; here we simulate with PyTorch code and note where a kernel would go.

```python
# optimized_mlp_cloth.py
import torch
from torch.cuda.amp import autocast

class HashCache:
    def __init__(self, resolution, scale=1.0):
        self.res = resolution
        self.scale = scale
        self.cache = {}  # dictionary for simplicity
    def get_cached(self, x):
        """
        Return cached value if exists; else None. x is (batch,3).
        """
        key = tuple((x * self.res * self.scale).round().long().view(-1).cpu().numpy())
        return self.cache.get(key, None)
    def update_cache(self, x, value):
        key = tuple((x * self.res * self.scale).round().long().view(-1).cpu().numpy())
        self.cache[key] = value.detach().cpu().numpy()

model_fp16 = SineMLP().cuda().half()  # model in half precision
amp_scaler = torch.cuda.amp.GradScaler()

hash_cache = HashCache(resolution=128, scale=0.1)

def forward_with_cache(inp):
    """
    Forward pass with caching and fp16. inp is FloatTensor.
    """
    # Convert to FP16
    inp = inp.cuda()
    # Check cache for positions (assuming first 3 dims are xyz)
    xyz = inp[:, :3]
    cached = hash_cache.get_cached(xyz)
    if cached is not None:
        # Use cached output (wrap as tensor)
        return torch.from_numpy(cached).to('cuda').half()
    # Otherwise compute
    with autocast():
        out = model_fp16(inp.half())
    # Update cache for these xyz
    hash_cache.update_cache(xyz, out)
    return out

# Example inference with FP16 and caching
inp = torch.randn(100, 8)  # 8 inputs (3xyz + t + 3force + 1mat)
out = forward_with_cache(inp)
```

In practice, the `HashCache` would use a sparse multi-resolution grid (like Tiny CUDA NN) for speed. We simulate caching with a simple dict keyed by quantized positions. The code uses `torch.cuda.amp.autocast()` to automatically use FP16 in supported ops. One could also write a **tiny CUDA kernel** to compute the physics losses or SDF queries more efficiently; if not available, the above Python code falls back to GPU tensor ops. These optimizations significantly reduce latency during real-time updates.

```python
pcd_model  = o3d.geometry.PointCloud(o3d.utility.Vector3dVector(model_pts))
dists1 = pcd_target.compute_point_cloud_distance(pcd_model)
dists2 = pcd_model.compute_point_cloud_distance(pcd_target)
chamfer = np.mean(dists1)**0.5 + np.mean(dists2)**0.5

# Normal consistency: average absolute dot product of nearest normals
target_normals = np.asarray(target_mesh.vertex_normals)
model_normals  = np.asarray(model_mesh.vertex_normals)
# For simplicity, align by index
norm_dot = np.abs((target_normals * model_normals).sum(axis=1))
norm_consistency = np.mean(norm_dot)

print(f"Chamfer distance: {chamfer:.4f}, Normal consistency: {norm_consistency:.4f}")

# Measure FPS of neural inference
import torch
model = SineMLP().cuda()
dummy_input = torch.randn(1000, 8).cuda()
# Warmup
for _ in range(10): _ = model(dummy_input)
# Benchmark
start = time.time()
for _ in range(100):
    _ = model(dummy_input)
fps = 100 / (time.time() - start)
print(f"Neural model inference: {fps:.1f} FPS")

# Plot example cloth shape vs baseline
fig = plt.figure(figsize=(8,4))
ax1 = fig.add_subplot(121, projection='3d')
ax1.scatter(target_pts[:,0], target_pts[:,1], target_pts[:,2], s=1, c='b')
ax1.set_title("Target Cloth")
ax2 = fig.add_subplot(122, projection='3d')
ax2.scatter(model_pts[:,0], model_pts[:,1], model_pts[:,2], s=1, c='r')
ax2.set_title("Neural Cloth Prediction")
plt.show()
```

This notebook computes quantitative metrics and visualizes cloth meshes. In practice, one would use larger test sequences, multiple time steps, and more robust Chamfer implementations (e.g. from PyTorch3D). The plot shows sample deformations for qualitative comparison.
