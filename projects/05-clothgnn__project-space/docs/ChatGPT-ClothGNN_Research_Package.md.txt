## 2. Dataset Builder

We provide **Python scripts** to generate simulated cloth and hair datasets using industry tools. These scripts illustrate how to automate data creation, labeling, and export in HDF5/CSV formats.

- **Cloth (CLO3D or Marvelous Designer):** We simulate a 3-second cloak draping scenario. The code below uses a hypothetical Python API to load an avatar and garment pattern, sew seams, run the physics simulation, and extract vertex trajectories. We auto-label seams, compute triangle shear and strain energy density for each triangle, and tag material (fabric) per vertex. Data is saved in HDF5.

```python
import numpy as np
import h5py
# Hypothetical APIs for CLO3D or Marvelous Designer
from garment_sim import Simulator, Mesh, Pattern

# Initialize simulator (e.g., Marvelous Designer)
sim = Simulator(engine='MarvelousDesigner')  # or 'CLO3D'
# Load a human avatar mesh
avatar = Mesh.load_obj('avatar.obj')
sim.load_avatar(avatar)
# Load cloth pattern for a cloak (2D patterns for front/back)
pattern = Pattern.load('cloak_pattern.json')
sim.load_pattern(pattern)
# Auto-sew pattern pieces along designated edges
sim.auto_sew_patterns()
# Assign material properties (e.g., silk fabric) to garment
sim.set_material('cloak', density=0.001, stiffness=100.0, damping=0.01)

# Run the physics simulation for 3 seconds (at 60 FPS)
sim.simulate(duration=3.0, fps=60)

# Extract simulation data: vertex positions over time
vertex_tracks = sim.get_vertex_positions()  
# vertex_tracks: numpy array shape (T+1, V, 3), where T=180 frames, V vertices

# Label seams: identify vertices on seams (boolean mask per vertex)
seam_vertices = sim.identify_seam_vertices()  
# e.g., returns boolean array shape (V,) where True if on a seam

# Compute triangle shear and strain energy density for each triangle at each frame
# We assume we have the rest (initial) mesh for reference
triangles = avatar.faces  # shape (F, 3) indices of vertices per face
rest_positions = vertex_tracks[0]  # initial rest positions (no motion yet)
F = len(triangles)
T = len(vertex_tracks) - 1

# Placeholder fabric stiffness constants (for energy calc)
stretch_k = 100.0

# Arrays to store computed labels (shape (T+1, F))
triangle_shear = np.zeros((T+1, F))
triangle_energy = np.zeros((T+1, F))

for t in range(T+1):
    pos = vertex_tracks[t]  # positions at time t
    # Compute shear per triangle: here defined as difference in angle from rest
    for i, (v0,v1,v2) in enumerate(triangles):
        # Current triangle vectors
        e01 = pos[v1] - pos[v0]
        e02 = pos[v2] - pos[v0]
        # Rest triangle vectors
        r01 = rest_positions[v1] - rest_positions[v0]
        r02 = rest_positions[v2] - rest_positions[v0]
        # Compute current and rest angle between edges
        def tri_angle(a,b):
            cos = np.dot(a,b) / (np.linalg.norm(a)*np.linalg.norm(b)+1e-6)
            return np.arccos(np.clip(cos, -1, 1))
        angle_curr = tri_angle(e01, e02)
        angle_rest = tri_angle(r01, r02)
        triangle_shear[t, i] = abs(angle_curr - angle_rest)
        # Strain energy: sum of spring energies on edges
        energy = 0.0
        for (vA, vB) in [(v0,v1),(v1,v2),(v2,v0)]:
            L0 = np.linalg.norm(rest_positions[vB] - rest_positions[vA])
            L = np.linalg.norm(pos[vB] - pos[vA])
            energy += 0.5 * stretch_k * (L - L0)**2
        triangle_energy[t, i] = energy

# Prepare data export: per-vertex and per-triangle data
vertex_positions = vertex_tracks.reshape(-1, 3)  # (T+1)*V by 3
# Compute per-vertex displacements (from rest)
vertex_displacements = vertex_positions - np.tile(rest_positions, (T+1, 1))
# Material tags: assume all cloak vertices have material 'silk' = 1
material_tags = np.ones(len(rest_positions), dtype=int)

# Save to HDF5
with h5py.File('cloak_dataset.h5', 'w') as f:
    f.create_dataset('vertex_positions', data=vertex_positions)
    f.create_dataset('vertex_displacements', data=vertex_displacements)
    f.create_dataset('seam_vertices', data=np.repeat(seam_vertices, T+1))
    f.create_dataset('triangle_shear', data=triangle_shear)
    f.create_dataset('triangle_energy', data=triangle_energy)
    f.create_dataset('material_tags', data=material_tags)
```

*Comments:* The script uses a hypothetical `Simulator` API (which many cloth tools provide) to set up and run a cloth simulation. We record the 3D positions of all cloth vertices at each frame. Seams are automatically identified by the tool where garment pattern edges join. We then compute *triangle shear* as the change in angle between two edges of each triangle relative to the rest shape, and *strain energy* using a simple spring model. All data (vertex trajectories, displacements, seam flags, shear/energy labels, material IDs) are saved in HDF5 for use in training.

- **Hair (NVIDIA Flex):** We simulate a 3-second hair dynamics scenario using NVIDIA Flex (a particle-based physics simulator). For simplicity, we model hair as a set of connected particles (like a soft cloth or rod). The code below sketches how to use a Flex API to simulate and label hair strands. We assign different stiffness to represent hair strand elasticity. After simulation, we compute strand curvature and per-vertex energies similarly.

```python
import numpy as np
import h5py
# Hypothetical Flex Python binding
from flexsim import FlexSimulator

# Initialize Flex simulator
flex = FlexSimulator()
# Load a kinematic head or body to attach hair
flex.load_static_mesh('head.obj', position=[0,1.6,0])  # head at realistic height
# Generate hair strands as chains of particles (e.g., 100 strands, 20 particles each)
hair = []
num_strands = 100
particles_per_strand = 20
spacing = 0.02  # 2 cm between particles
for s in range(num_strands):
    strand_particles = []
    root_pos = np.array([0.0, 1.6, 0.0]) + np.random.randn(3)*0.1  # randomize root location
    for i in range(particles_per_strand):
        p = flex.add_particle(position=root_pos - np.array([0, spacing*i, 0]), mass=0.001)
        strand_particles.append(p)
        # Connect to previous particle with a distance spring
        if i > 0:
            flex.add_spring(prev= strand_particles[-2], curr= p, stiffness=500.0)
    hair.append(strand_particles)

# Fix the root particles to the head
for strand in hair:
    flex.fix_particle(strand[0])

# Run simulation (3 seconds)
flex.simulate(duration=3.0, timestep=0.01)

# Extract particle trajectories (T+1, N_particles, 3)
positions = flex.get_particle_positions()  # numpy array
T, N = positions.shape[0]-1, positions.shape[1]

# Identify hair segments (triangles not explicit, but we can compute curvature at each middle particle)
hair_curvature = np.zeros((T+1, num_strands, particles_per_strand-2))
hair_energy = np.zeros((T+1, num_strands, particles_per_strand-1))
for t in range(T+1):
    pos_t = positions[t]  # (N,3)
    idx = 0
    for s in range(num_strands):
        pts = pos_t[idx:idx+particles_per_strand]
        # Compute curvature: angle between two adjacent segments along strand
        for i in range(1, particles_per_strand-1):
            v1 = pts[i] - pts[i-1]
            v2 = pts[i+1] - pts[i]
            cos = np.dot(v1, v2) / (np.linalg.norm(v1)*np.linalg.norm(v2) + 1e-6)
            hair_curvature[t, s, i-1] = np.arccos(np.clip(cos, -1, 1))
        # Compute stretching energy on each spring
        for i in range(1, particles_per_strand):
            L0 = spacing
            L = np.linalg.norm(pts[i] - pts[i-1])
            hair_energy[t, s, i-1] = 0.5 * 500.0 * (L - L0)**2
        idx += particles_per_strand

# Save hair data (flattening as needed)
with h5py.File('hair_dataset.h5', 'w') as f:
    f.create_dataset('particle_positions', data=positions.reshape(-1, 3))
    f.create_dataset('hair_curvature', data=hair_curvature)
    f.create_dataset('hair_energy', data=hair_energy)
    # No seams or material for hair, but we could tag hair root vertices if needed
```

*Comments:* We define multiple hair strands attached to a head and simulate their dynamics. Each strand is a chain of Flex particles connected by springs. After simulation, we compute per-strand curvature (angle at each internal particle) and spring strain energy. The data (particle positions, curvature, energy) are saved to HDF5. In practice, one could also export strands as small connected meshes if needed for compatibility.

These dataset builders ensure each frame has rich labels: vertex positions and displacements, seam and material tags, triangle shear, curvature, and energy, all formatted for easy loading (e.g., via HDF5 libraries).

## 3. Collision Module

We implement a **PyTorch module** that creates a voxelized occupancy grid of obstacles (for static scene or self-collision) and integrates occupancy features into graph node inputs. Below is an example of a GPU-friendly occupancy grid generator. We assume 3D obstacles are given as meshes or implicit surfaces; for simplicity, we demonstrate occupancy from a bounding volume or SDF.

```python
import torch
import torch.nn as nn

class OccupancyGrid(nn.Module):
    """
    Generates a 3D occupancy grid for given obstacles and provides occupancy features for mesh nodes.
    """
    def __init__(self, grid_dim=32, bounds=((-1,1),(-1,2),(-1,1))):
        """
        Args:
            grid_dim (int): number of voxels per side (assume cubic grid).
            bounds (tuple): ((xmin,xmax),(ymin,ymax),(zmin,zmax)) world bounds of the grid.
        """
        super().__init__()
        self.grid_dim = grid_dim
        self.bounds = bounds
        # Create voxel centers coordinates (grid_dim^3 x 3)
        xs = torch.linspace(bounds[0][0], bounds[0][1], grid_dim)
        ys = torch.linspace(bounds[1][0], bounds[1][1], grid_dim)
        zs = torch.linspace(bounds[2][0], bounds[2][1], grid_dim)
        X, Y, Z = torch.meshgrid(xs, ys, zs, indexing='ij')
        self.register_buffer('voxel_centers', torch.stack([X,Y,Z], dim=-1).view(-1,3))

    def forward(self, node_positions, obstacle_sdf):
        """
        Args:
            node_positions (Tensor): shape (N,3) world coordinates of mesh vertices/nodes.
            obstacle_sdf (callable): a function f(x,y,z)->SDF value (<=0 inside obstacle).
        Returns:
            occupancy_feat (Tensor): shape (N,1) occupancy feature (0 or 1).
        """
        # Compute occupancy grid: 1 if inside any obstacle, else 0
        # We apply the SDF function on all voxel centers
        with torch.no_grad():
            # obstacle_sdf should take a (M,3) tensor and return (M,) SDF values
            sdf_vals = obstacle_sdf(self.voxel_centers)  # (grid_dim^3,)
            occupied = (sdf_vals <= 0).float()  # 1 if inside obstacle
        # Reshape to grid for sampling
        grid_occ = occupied.view(self.grid_dim, self.grid_dim, self.grid_dim)
        # Sample occupancy for each node position
        # Normalize node positions to grid index range [0, grid_dim-1]
        # Assuming node_positions within the same bounds
        mins = torch.tensor([self.bounds[0][0], self.bounds[1][0], self.bounds[2][0]], device=node_positions.device)
        maxs = torch.tensor([self.bounds[0][1], self.bounds[1][1], self.bounds[2][1]], device=node_positions.device)
        coords = (node_positions - mins) / (maxs - mins)  # normalized [0,1]
        coords = coords.clamp(0, 1)
        indices = (coords * (self.grid_dim-1)).long()  # (N,3) indices
        # Gather occupancy values at each node
        occ_vals = grid_occ[indices[:,0], indices[:,1], indices[:,2]].unsqueeze(-1)  # (N,1)
        return occ_vals

# Example usage within a GNN input preparation:
# node_pos: Tensor (N,3) of current cloth vertex positions
# Assume a spherical obstacle: SDF = ||x-center|| - radius
def sphere_sdf(points, center=torch.tensor([0.0,0.5,0.0]), radius=0.3):
    # points: (M,3)
    dist = torch.norm(points - center.to(points.device), dim=1)
    return dist - radius

voxelizer = OccupancyGrid(grid_dim=64, bounds=((-1,1),(0,2),(-1,1)))
node_positions = torch.rand((1024,3))*2 - 1  # example node positions in [-1,1] cube
occupancy_features = voxelizer(node_positions, sphere_sdf)  # shape (1024,1), on GPU if inputs on GPU
```

*Comments:* The `OccupancyGrid` class builds a 3D grid covering the scene bounds. In `forward`, it evaluates an obstacle SDF to mark which voxels are occupied. Then it converts each node’s 3D position into voxel indices and fetches the occupancy (1 if inside an obstacle, else 0). This operation is fully vectorized with PyTorch tensors (no Python loops). To integrate into a GNN, one can concatenate these occupancy features to each node’s feature vector (e.g. as an extra channel). For self-collision, one could similarly compute an SDF of the cloth’s own volume (treat previous-frame cloth mesh as “obstacle”) to discourage self-intersections. This occupancy feature provides the GNN with spatial context about collisions.

## 4. ClothGNN Model (Encoder → GRU → Decoder)

We implement a **recurrent GNN** in PyTorch Geometric style. The model encodes the mesh (nodes with positions/velocities, edges from mesh connectivity) into hidden states, applies a GRU for temporal dynamics, and decodes to predict next-frame vertex displacements or accelerations. We also outline optional equivariant layers and auxiliary loss terms for seams/shear.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import MessagePassing, global_mean_pool
from torch_geometric.utils import add_self_loops

class ClothEncoder(MessagePassing):
    """
    GNN-based encoder that processes mesh node and edge features into latent node embeddings.
    """
    def __init__(self, in_channels, hidden_channels):
        super().__init__(aggr='mean')  # mean aggregation
        self.lin_node = nn.Linear(in_channels, hidden_channels)
        self.lin_edge = nn.Linear(in_channels, hidden_channels)
        self.lin_msg = nn.Linear(hidden_channels, hidden_channels)

    def forward(self, x, edge_index):
        # x: (N, F_node), e.g. [pos, vel, material, seam_flag, occupancy,...]
        # edge_index: (2,E)
        x = self.lin_node(x)  # initial projection
        # propagate messages
        return self.propagate(edge_index, x=x)

    def message(self, x_j, edge_index, size):
        # x_j: sender node features
        # Here we simply use sender features as message
        return F.relu(self.lin_msg(x_j))

    def update(self, aggr_out):
        # Combine aggregated messages with node features
        return aggr_out  # identity in this simple case

class ClothDecoder(nn.Module):
    """
    GNN-based decoder that maps latent node embeddings to displacement/velocity predictions.
    """
    def __init__(self, hidden_channels, out_channels):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(hidden_channels, hidden_channels),
            nn.ReLU(),
            nn.Linear(hidden_channels, out_channels)
        )
    def forward(self, h):
        return self.mlp(h)  # e.g. predict acceleration (ax,ay,az) or delta positions

class ClothGNNModel(nn.Module):
    def __init__(self, node_feat_dim, hidden_dim):
        super().__init__()
        self.encoder = ClothEncoder(in_channels=node_feat_dim, hidden_channels=hidden_dim)
        self.gru = nn.GRUCell(hidden_dim, hidden_dim)
        self.decoder = ClothDecoder(hidden_dim, out_channels=3)  # predict 3D displacement
        # Optional: equivariant layer placeholder (e.g., E(n) Equivariant GNN) could be added

    def forward(self, data, h):
        """
        data: PyG data object with data.x (N,feat), data.edge_index, etc.
        h: (N, hidden_dim) previous hidden state
        Returns: predictions (N,3), new hidden state (N,hidden_dim)
        """
        # Encode current features to latent
        h_enc = self.encoder(data.x, data.edge_index)
        # Update hidden state with GRU
        h_next = self.gru(h_enc, h)
        # Decode to predict displacement or acceleration
        pred = self.decoder(h_next)
        return pred, h_next

# Example: Initialize model with 16 initial features per node
node_feat_dim = 16
hidden_dim = 64
model = ClothGNNModel(node_feat_dim, hidden_dim)
```

**Loss Functions:** In addition to standard losses (e.g. L2 between predicted and true vertex displacements), we introduce auxiliary losses to enforce seam and shear constraints. Suppose $\hat{\mathbf{u}}\_i$ and $\mathbf{u}\_i$ are predicted and ground-truth displacements of node $i$; let $E$ be the set of edges, and $S$ the set of seam edges. We can define:

- **Position Loss:**
  $
  L\_{\text{pos}} = \frac{1}{N}\sum\_{i=1}^N |\hat{\mathbf{u}}\_i - \mathbf{u}\_i|^2.
  $
- **Edge-Length Loss:** (to preserve rest edge lengths)
  $
  L\_{\text{edge}} = \frac{1}{|E|}\sum\_{(i,j)\in E} \Big(|(\mathbf{p}\_i+\hat{\mathbf{u}}\_i) - (\mathbf{p}*j+\hat{\mathbf{u}}*j)| - L*{ij}^0\Big)^2,
  $
  where $L*{ij}^0$ is rest length.
- **Shear Loss:** (triangle shear preservation) for each triangle $(i,j,k)$:
  $
  L\_{\text{shear}} = \frac{1}{|\triangle|}\sum\_{\triangle}\bigl|\Delta\theta\_\triangle - \Delta\theta\_\triangle^{gt}\bigr|^2,
  $
  where $\Delta\theta\_\triangle$ is the predicted change in angle (as computed in Dataset) and $\Delta\theta^{gt}$ the ground-truth.
- **Seam Curvature Loss:** for edges on seams $S$, penalize discontinuity:
  $
  L\_{\text{seam}} = \frac{1}{|S|}\sum\_{(i,j)\in S}|\hat{\mathbf{u}}\_i - \hat{\mathbf{u}}\_j|^2.
  $
  This encourages nearby seam vertices to move consistently (preserving smooth seam bending).
- **Total Loss:** combine them:
  $
  L = \lambda\_p L\_{\text{pos}} + \lambda\_e L\_{\text{edge}} + \lambda\_s L\_{\text{shear}} + \lambda\_c L\_{\text{seam}}.
  $
  Hyperparameters $\lambda$ weight each term (e.g. $\lambda\_p=1$, others smaller).

*Documentation:* Each component is commented. The `ClothGNNModel` takes a graph (`data`) with node features (which should include current position, velocity, seam flags, occupancy from the collision module, material ID, etc.). It encodes node features via a message-passing network (`ClothEncoder`), updates a GRU per node to retain memory of past motion, and decodes predictions. One can plug in equivariant layers (e.g. EGNN) by replacing `ClothEncoder` with an equivariant message-passing class. Auxiliary loss terms (shear, seam) are derived from the labels computed in the dataset builder; they ensure the model respects cloth-specific constraints.

## 5. Training Script

We sketch a PyTorch training script that implements **curriculum learning** and data augmentation. The curriculum gradually increases difficulty by varying wind forces and collision intensity. Data augmentation applies random rotations and scaling to meshes. The script shows command-line options for flexibility.

```python
import argparse
import torch
from torch.utils.data import DataLoader
from torchvision import transforms

# Assume we have a PyG Dataset class ClothDataset that yields (graph, target) pairs
class ClothDataset(torch.utils.data.Dataset):
    def __init__(self, data_files, transform=None, wind_strength=0.0):
        self.data_files = data_files
        self.transform = transform
        self.wind_strength = wind_strength  # intensity of random wind forces
    def __len__(self):
        return len(self.data_files)
    def __getitem__(self, idx):
        # Load pre-generated data (positions, displacements, features)
        data = torch.load(self.data_files[idx])  # custom load
        # Apply augmentation: e.g., random rotation around Y axis
        if self.transform:
            data = self.transform(data)
        # Optionally add wind disturbances to vertex positions/velocities
        if self.wind_strength > 0:
            # perturb node features (velocities) with random wind vector
            wind = torch.randn_like(data.x[:,0:3]) * self.wind_strength
            data.x[:,0:3] += wind  # adding to velocity channels, for example
        return data, data.y  # input graph and target displacements

# Augmentation: random rotation and uniform scaling
class RandomRotate:
    def __call__(self, data):
        theta = torch.rand(1).item() * 2*3.1415
        rot = torch.tensor([[torch.cos(theta), 0, -torch.sin(theta)],
                            [0, 1, 0],
                            [torch.sin(theta), 0,  torch.cos(theta)]])
        # Apply to positions and velocities
        data.x[:, :3] = (rot @ data.x[:, :3].T).T
        data.y = (rot @ data.y.T).T
        return data

class RandomScale:
    def __init__(self, scale_range=(0.9,1.1)):
        self.smin, self.smax = scale_range
    def __call__(self, data):
        s = torch.rand(1).item()*(self.smax-self.smin) + self.smin
        data.x[:, :3] *= s
        data.y *= s
        return data

# Training function
def train(model, dataloader, optimizer, epoch):
    model.train()
    total_loss = 0.0
    for data, target in dataloader:
        data = data.to(device)
        target = target.to(device)
        optimizer.zero_grad()
        h0 = torch.zeros(data.num_nodes, model.encoder.lin_msg.out_features, device=device)
        pred, _ = model(data, h0)
        loss_pos = F.mse_loss(pred, target)
        # (Compute other losses here using data.seam_flags, etc., if needed)
        loss = loss_pos  # + lambda * other losses
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    print(f"Epoch {epoch}: Loss = {total_loss/len(dataloader):.4f}")

# Main
parser = argparse.ArgumentParser()
parser.add_argument('--data_dir', type=str, default='cloth_data/')
parser.add_argument('--epochs', type=int, default=100)
parser.add_argument('--batch_size', type=int, default=8)
parser.add_argument('--initial_wind', type=float, default=0.0)
parser.add_argument('--max_wind', type=float, default=0.1)
parser.add_argument('--curriculum_epochs', type=int, default=50)
args = parser.parse_args()

# Prepare dataset files list
data_files = [f"{args.data_dir}/frame_{i}.pt" for i in range(1000)]  # example
# Define augmentation pipeline
augmentations = transforms.Compose([RandomRotate(), RandomScale((0.9,1.1))])

# Training setup
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = ClothGNNModel(node_feat_dim=16, hidden_dim=64).to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# Curriculum: linearly increase wind strength from initial to max
for epoch in range(1, args.epochs+1):
    # Determine current wind strength
    if epoch < args.curriculum_epochs:
        wind = args.initial_wind + (args.max_wind - args.initial_wind) * (epoch / args.curriculum_epochs)
    else:
        wind = args.max_wind
    # Create dataset and loader for this epoch
    dataset = ClothDataset(data_files, transform=augmentations, wind_strength=wind)
    loader = DataLoader(dataset, batch_size=args.batch_size, shuffle=True)
    train(model, loader, optimizer, epoch)
    # (Optionally adjust learning rate, monitor metrics, save checkpoints, etc.)
```

*Comments:* This script constructs a training loop with **curriculum learning**: the `wind_strength` parameter gradually increases from `initial_wind` to `max_wind` over `curriculum_epochs` epochs. Each data sample may have random wind perturbations added to node velocities. We also apply **data augmentation**: random rotations about the vertical axis and slight uniform scaling of the mesh (common in cloth data augmentation) to improve generalization. The parser options allow easy adjustment of hyperparameters. The `train` function demonstrates computing the basic loss; one could insert additional loss terms (edge, shear, seam losses) similarly. Standard best practices (e.g. learning rate scheduling, validation splits, gradient clipping) can be added.

## 6. Export Pipeline

After predicting cloth/hair motion, we provide a script to **export results to USD** (Universal Scene Description) format for interoperability. We use Pixar’s USD Python API (`pxr`). The script creates a USD scene, defines a mesh with animated vertex positions, and writes to disk. We also outline integration snippets for Unity and NVIDIA Omniverse.

```python
from pxr import Usd, UsdGeom, Gf

def export_to_usd(filename, mesh_name, vertices, faces, frame_rate=60):
    """
    Exports a deforming mesh to USD as a motion sequence.
    vertices: list of T tensors each (V,3)
    faces: (F,3) int array of indices
    """
    stage = Usd.Stage.CreateNew(filename)
    stage.SetStartTimeCode(0)
    stage.SetEndTimeCode(len(vertices)-1)
    stage.SetTimeCodesPerSecond(frame_rate)
    # Define a mesh prim
    mesh = UsdGeom.Mesh.Define(stage, f"/{mesh_name}")
    mesh.GetFaceVertexCountsAttr().Set([3] * len(faces))  # triangles
    mesh.GetFaceVertexIndicesAttr().Set(list(faces.flatten()))
    # Set static topology
    mesh.CreateDoubleSidedAttr().Set(True)
    # For each frame, set the point positions
    for t, verts in enumerate(vertices):
        time = t  # one time step per frame index
        mesh.GetPointsAttr().Set([Gf.Vec3f(*v.tolist()) for v in verts], time)
    stage.GetRootLayer().Save()

# Example usage:
vertices = [torch.randn((100,3)).cpu() for _ in range(180)]  # list of 180 frames, 100 vertices
faces = np.array([[0,1,2], [2,3,0], ...])  # cloth mesh faces
export_to_usd('cloth_motion.usd', 'ClothMesh', vertices, faces, frame_rate=60)
```

*Comments:* We define a USD `Mesh` prim and set its topology (face indices). Then for each frame we assign the vertex positions via `GetPointsAttr().Set(points, time)`, using USD’s time-sampled attributes. This results in a USD file where the mesh deforms over time.

**Integration snippets:**

# Chamfer distance implementation (basic)
def chamfer_distance(pc1, pc2):
    # pc1, pc2: (N,3) point clouds (e.g. vertices of meshes)
    # returns sum of squared distances between nearest points
    pc1 = torch.tensor(pc1, device=device)
    pc2 = torch.tensor(pc2, device=device)
    # Compute pairwise distances (N1 x N2)
    diff = pc1.unsqueeze(1) - pc2.unsqueeze(0)  # (N1,N2,3)
    dist2 = (diff**2).sum(-1)
    cd1 = dist2.min(dim=1)[0].mean()
    cd2 = dist2.min(dim=0)[0].mean()
    return cd1 + cd2
