Chemotactic migration modeling has seen a surge of **data-driven and physics-informed approaches**. Recent works use machine learning to bridge scales: for example, data-driven PDE discovery techniques infer macroscale chemotaxis equations from either simulations or experiments【41†L21-L29】【36†L82-L90】. These methods often treat unknown chemotactic flux terms with black-box regressors or embed known diffusion terms in gray-box models. Embedding theorems (Whitney/Takens) and coordinate-invariant representations help avoid explicit nutrient measurements【36†L82-L90】. Similarly, high-fidelity agent-based simulations have enabled learning of effective Keller–Segel–type PDEs via automatic relevance determination and Gaussian processes【41†L21-L29】. Overall, a trend is to leverage **hybrid ML–PDE pipelines**: training neural nets to honor known physics while fitting data.

Geometric and physics-informed deep learning are emerging in related domains. For instance, PINNs are being applied to cell mechanics and migration: a PINN solved a free-boundary actomyosin flow problem, integrating complex biophysical terms directly into the loss【44†L316-L324】. Geometric learning of paths has been explored in robotics and graphics (e.g. neural solvers for geodesic distance satisfying the Eikonal equation【38†L97-L105】【38†L167-L173】). These PINN approaches suggest **scalability to high dimensions** and provide smooth differentiable solutions, but they often require careful training (indeed data augmentation helped geodesic PINNs stabilize convergence【38†L97-L105】).

However, **limitations and gaps** remain when forecasting individual microbe trajectories. Classical PDE models (e.g. Keller–Segel) capture population densities but require full knowledge of nutrient fields and often assume continuum limits【36†L121-L129】. Most ML-PDE methods also focus on collective densities, not on single-cell paths. Explicitly learning the underlying nutrient field is hard, though some work shows density history can approximate it【36†L82-L90】. Crucially, **geometry has been under-exploited**: microbes likely follow (near-)geodesic paths on an evolving nutrient landscape, but no framework directly enforces such manifold constraints in chemotactic models. Data-driven methods often lack *geometric priors* (e.g., curvature-minimizing trajectories). Finally, many existing methods assume static or predefined domains, whereas real environments evolve over time as cells consume nutrients.

In summary, the literature reveals a push towards **hybrid physics-ML models** for chemotaxis: learning effective PDEs from data, using PINNs for biophysical cell models, and beginning to apply geometric PINN ideas to path planning【36†L82-L90】【44†L316-L324】【38†L97-L105】. The clear gaps are in integrating **single-cell trajectory modeling** with dynamic nutrient fields and geometric constraints. Our proposed “Cell-Path PINNs” kit addresses these gaps by treating each microbe’s trajectory as a geodesic on a learned, time-varying nutrient manifold, enforced via PINN losses. This leverages the strengths of geometric deep learning (smooth manifold paths) and physics-informed learning (chemotaxis PDE structure) to forecast trajectories with minimal supervision.

```python
# Dependencies: torch, torchvision, OpenCV (cv2), numpy, pandas
import torch
import torch.nn as nn
import torchvision.transforms as transforms
import cv2
import numpy as np
import pandas as pd

# Define a simple U-Net architecture
class DoubleConv(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(in_ch, out_ch, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_ch), nn.ReLU(inplace=True),
            nn.Conv2d(out_ch, out_ch, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_ch), nn.ReLU(inplace=True)
        )
    def forward(self, x):
        return self.net(x)

class UNet(nn.Module):
    def __init__(self, in_ch=1, out_ch=1, features=[64, 128, 256, 512]):
        super().__init__()
        # Encoder (Down-sampling)
        self.downs = nn.ModuleList()
        self.pools = nn.ModuleList()
        prev_ch = in_ch
        for f in features:
            self.downs.append(DoubleConv(prev_ch, f))
            self.pools.append(nn.MaxPool2d(2))
            prev_ch = f
        # Bottleneck
        self.bottleneck = DoubleConv(prev_ch, prev_ch*2)
        # Decoder (Up-sampling)
        self.ups = nn.ModuleList()
        self.up_convs = nn.ModuleList()
        for f in reversed(features):
            self.ups.append(nn.ConvTranspose2d(prev_ch*2, f, kernel_size=2, stride=2))
            self.up_convs.append(DoubleConv(f*2, f))
            prev_ch = f
        self.final = nn.Conv2d(features[0], out_ch, kernel_size=1)

    def forward(self, x):
        skip_connections = []
        # Encoder
        for down, pool in zip(self.downs, self.pools):
            x = down(x)
            skip_connections.append(x)
            x = pool(x)
        # Bottleneck
        x = self.bottleneck(x)
        skip_connections = skip_connections[::-1]
        # Decoder
        for up, conv in zip(self.ups, self.up_convs):
            x = up(x)
            skip = skip_connections.pop(0)
            # concatenate along channel dimension
            x = torch.cat([x, skip], dim=1)
            x = conv(x)
        return torch.sigmoid(self.final(x))

# Load a pre-trained U-Net model (assumed trained on similar microbe images)
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
unet = UNet(in_ch=1, out_ch=1).to(device)
unet.load_state_dict(torch.load('unet_model.pth', map_location=device))
unet.eval()

# Video processing: segment frames and find centroids
cap = cv2.VideoCapture('microscope_video.mp4')
centroid_records = []  # list of (frame_idx, x, y)

frame_idx = 0
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.5], std=[0.5])  # adjust as needed
])
while True:
    ret, frame = cap.read()
    if not ret:
        break
    # Preprocess: convert to grayscale and normalize
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    inp = transform(gray).unsqueeze(0).to(device)  # shape (1,1,H,W)
    with torch.no_grad():
        mask = unet(inp)  # output shape (1,1,H,W)
    mask_np = mask.squeeze().cpu().numpy()
    # Threshold to binary mask
    _, mask_bin = cv2.threshold((mask_np*255).astype(np.uint8), 127, 255, cv2.THRESH_BINARY)
    # Find contours of segmented microbes
    contours, _ = cv2.findContours(mask_bin, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for cnt in contours:
        # Compute centroid of each contour
        M = cv2.moments(cnt)
        if M['m00'] == 0:
            continue
        cx = int(M['m10']/M['m00'])
        cy = int(M['m01']/M['m00'])
        centroid_records.append({'frame': frame_idx, 'x': cx, 'y': cy})
    frame_idx += 1

cap.release()
# Save centroids to CSV
df = pd.DataFrame(centroid_records, columns=['frame','x','y'])
df.to_csv('centroids.csv', index=False)
```

### (c) Synthetic Data Generator (Boids Algorithm)

```python
import numpy as np
import pandas as pd

def generate_boids(n_boids=50, steps=200, dt=0.1, space_size=100):
    """
    Generate synthetic trajectories for boids-like swarm (simulating chemotactic motion).
    Returns a DataFrame with columns: boid_id, t, x, y.
    """
    # Initialize positions and velocities
    pos = np.random.rand(n_boids, 2) * space_size
    vel = (np.random.rand(n_boids, 2) - 0.5) * 2  # random initial velocities
    trajectories = []

    for t in range(steps):
        for i in range(n_boids):
            trajectories.append({'boid_id': i, 't': t*dt, 'x': pos[i,0], 'y': pos[i,1]})
        # Boids rules (separation, alignment, cohesion)
        for i in range(n_boids):
            neighbors = []
            for j in range(n_boids):
                if j != i:
                    dist = np.linalg.norm(pos[j] - pos[i])
                    if dist < 15:  # neighbor radius
                        neighbors.append(j)
            # Initialize rule vectors
            v_separation = np.zeros(2)
            v_alignment = np.zeros(2)
            v_cohesion = np.zeros(2)
            if neighbors:
                # Separation: steer away from nearby boids
                for j in neighbors:
                    diff = pos[i] - pos[j]
                    dist = np.linalg.norm(diff)
                    if dist > 0:
                        v_separation += diff / dist  # weighted by inverse distance
                # Alignment: match velocity
                avg_vel = np.mean(vel[neighbors], axis=0)
                v_alignment = avg_vel - vel[i]
                # Cohesion: move towards center of mass
                center = np.mean(pos[neighbors], axis=0)
                v_cohesion = center - pos[i]
            # Update velocity with weighted rules
            vel[i] += 0.02*v_separation + 0.01*v_alignment + 0.005*v_cohesion
            # Limit maximum speed
            speed = np.linalg.norm(vel[i])
            if speed > 2.0:
                vel[i] = vel[i] / speed * 2.0
        # Update positions
        pos += vel * dt
    # Save to DataFrame
    df = pd.DataFrame(trajectories)
    df.to_csv('synthetic_boids.csv', index=False)
    return df

# Generate and save synthetic trajectories
df_synthetic = generate_boids(n_boids=20, steps=100, dt=0.5)
print("Synthetic data generated with {} trajectories".format(len(df_synthetic)))
```

This code simulates `n_boids` agents moving in 2D with simple boids rules, outputting `(x,y)` for each agent at each time step. It saves a CSV `synthetic_boids.csv` with columns `boid_id, t, x, y`. Dependencies: `numpy`, `pandas`.

## Step 3: PINN Model

We design a PINN that learns microbe trajectories `(x(t), y(t))` given `(x,y,t)` inputs, enforcing **constant-speed geodesics** and a latent **chemotactic potential field**.

**Model Architecture:** We use two neural networks:

- **Path Network**: $ \mathbf{r}(t) = (x(t), y(t)) = \mathrm{PathNet}(t) $. Input is time $t$; output is the 2D position. This implicitly parameterizes the trajectory.
- **Potential Network**: $ U(x,y,t) = \mathrm{PotentialNet}(x, y, t) $. Input is space-time coordinates; output is a scalar potential field (chemotactic nutrient).

```python
import torch
import torch.nn as nn
import torch.autograd as autograd

# Define the Path Network: input t -> output (x,y)
class PathNet(nn.Module):
    def __init__(self, hidden_dim=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(1, hidden_dim), nn.Tanh(),
            nn.Linear(hidden_dim, hidden_dim), nn.Tanh(),
            nn.Linear(hidden_dim, 2)  # outputs x and y
        )
    def forward(self, t):
        return self.net(t)

# Define the Potential Network: input (x,y,t) -> output scalar U
class PotentialNet(nn.Module):
    def __init__(self, hidden_dim=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(3, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, 1)   # scalar potential
        )
    def forward(self, x, y, t):
        inp = torch.cat([x, y, t], dim=1)  # shape (batch,3)
        return self.net(inp)

# Instantiate networks
path_net = PathNet(hidden_dim=64).to(device)
potential_net = PotentialNet(hidden_dim=64).to(device)
```

**Physical Constraints & Loss Terms:**

1. **Data Loss (Trajectory Fitting):** Match network trajectory to observed centroids $(x\_{\text{data}}(t\_i), y\_{\text{data}}(t\_i))$. E.g. using MSE:
   $
   L\_{\text{data}} = \sum\_i \big| \mathbf{r}(t\_i) - \mathbf{r}\_{\text{data}}(t\_i) \big|^2.
   $

2. **Geodesic Loss (Constant Speed):** Enforce that the speed $|\mathbf{r}'(t)|$ is constant (e.g. 1). If $\mathbf{v}(t) = \mathbf{r}'(t)$, we impose $|\mathbf{v}|^2 = c^2$. In practice:
   $
   L\_{\text{geo}} = \sum\_i \Big( |\mathbf{v}(t\_i)|^2 - 1 \Big)^2,
   $
   or equivalently penalize tangential acceleration: $\mathbf{v}\cdot \mathbf{a} = 0$ ⇒ $(x'x'' + y'y'')^2$. Here we use the simpler constant-speed loss.

3. **Chemotactic Potential Loss:** Encourage motion along the gradient of $U$. If cells move up the nutrient gradient, we expect
   $
   \mathbf{v}(t) \approx \nabla U(\mathbf{r}(t),t).
   $
   Using autograd, compute $\nabla U$ at $(x(t),y(t),t)$. The loss is
   $
   L\_{\text{chem}} = \sum\_i | \mathbf{v}(t\_i) - \nabla U(x(t\_i),y(t\_i),t\_i) |^2.
   $
   (Sign convention depends on definition; here positive gradient means moving toward higher concentration.)

4. **PDE/Regularization (Optional):** We may also impose a diffusion-consumption PDE on $U$, e.g. $\partial\_t U = D \Delta U - \alpha \rho$ (nutrient diffusion minus uptake by microbes), as a residual loss if data allow.

The **total loss** is a weighted sum: $L = \lambda\_d L\_{\text{data}} + \lambda\_g L\_{\text{geo}} + \lambda\_c L\_{\text{chem}} + \dots$.

```python
# Example loss computation for a batch of time points
# t: tensor of shape (N,1) with requires_grad=True
# x_data, y_data: ground-truth positions (N,1)
t = torch.linspace(0, 10, steps=100, requires_grad=True).view(-1,1).to(device)
x_pred, y_pred = path_net(t).chunk(2, dim=1)  # each is (N,1)
# Data loss
loss_data = ((x_pred - x_data)**2 + (y_pred - y_data)**2).mean()
# Compute velocity by autograd: v = dr/dt
v = autograd.grad(outputs=(x_pred.sum()+y_pred.sum()), inputs=t, create_graph=True)[0]  # derivative of (x+y) w.r.t. t
# NOTE: The above line computes d(x_pred+y_pred)/dt; in practice compute dx/dt, dy/dt separately:
dx_dt = autograd.grad(x_pred.sum(), t, create_graph=True)[0]
dy_dt = autograd.grad(y_pred.sum(), t, create_graph=True)[0]
# Geodesic (constant-speed) loss: enforce speed^2 = 1
speed_sq = dx_dt**2 + dy_dt**2
loss_geo = ((speed_sq - 1.0)**2).mean()
# Potential field gradients
U_pred = potential_net(x_pred, y_pred, t)  # shape (N,1)
# Gradient of U w.r.t spatial inputs
grad_U = autograd.grad(U_pred.sum(), [x_pred, y_pred], create_graph=True)
Ux, Uy = grad_U[0], grad_U[1]  # both (N,1)
# Chemotactic loss: velocity ~ gradient of U
loss_chem = ((dx_dt - Ux)**2 + (dy_dt - Uy)**2).mean()
# Total loss
loss = loss_data + 0.1*loss_geo + 1.0*loss_chem
loss.backward()
```

In practice, all derivatives (`dx_dt, dy_dt, Ux, Uy`) are obtained via PyTorch's autograd. The above code comments highlight the loss terms and their computation. One should also include regularization (e.g. weight decay) and possibly normalization of inputs.

**Equations and Comments:**

- The **Keller–Segel model** (density PDE) motivates our approach【36†L121-L129】 but we work at the single-cell level.
- We explicitly enforce *constant-speed geodesic motion* by constraining $|\mathbf{r}'(t)|$ to a constant, capturing the notion of minimal-energy paths on the nutrient manifold.
- The chemotactic term is encoded by learning a latent potential $U(x,y,t)$ whose gradient drives motion. This reflects physics: cells tend to move up nutrient gradients.
- All equations are enforced in the loss, making our NN *physics-informed*.

## Step 4: Training and Hyperparameter Tuning

### Training Notebook Code

Below is a representative training loop using PyTorch. This would be placed in a Jupyter notebook, leveraging a 16 GB GPU if available. We assume data loaders (`train_loader`) providing batches of `(t, x_true, y_true)`.

```python
# Example training loop for the PINN (in a Jupyter notebook)
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset
import matplotlib.pyplot as plt

# Prepare training data (e.g., from centroids.csv or synthetic data)
# t_data, x_data, y_data: 1D numpy arrays of equal length
t_tensor = torch.tensor(t_data, dtype=torch.float32).view(-1,1).to(device)
x_tensor = torch.tensor(x_data, dtype=torch.float32).view(-1,1).to(device)
y_tensor = torch.tensor(y_data, dtype=torch.float32).view(-1,1).to(device)
dataset = TensorDataset(t_tensor, x_tensor, y_tensor)
train_loader = DataLoader(dataset, batch_size=64, shuffle=True)

# Optimizer
optimizer = optim.Adam(list(path_net.parameters()) + list(potential_net.parameters()), lr=1e-3)
# Learning rate scheduler (optional)
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=500, gamma=0.5)

num_epochs = 2000
for epoch in range(num_epochs):
    epoch_loss = 0.0
    for t_batch, x_batch, y_batch in train_loader:
        t_batch.requires_grad = True  # enable gradients w.r.t. t
        optimizer.zero_grad()
        # Forward pass: predict position
        xy_pred = path_net(t_batch)       # (batch,2)
        x_pred = xy_pred[:,0:1]; y_pred = xy_pred[:,1:2]
        # Data loss
        loss_data = ((x_pred - x_batch)**2 + (y_pred - y_batch)**2).mean()
        # Velocity via autograd
        dx_dt = autograd.grad(x_pred.sum(), t_batch, create_graph=True)[0]
        dy_dt = autograd.grad(y_pred.sum(), t_batch, create_graph=True)[0]
        speed_sq = dx_dt**2 + dy_dt**2
        loss_geo = ((speed_sq - 1.0)**2).mean()
        # Potential and its gradient
        U_pred = potential_net(x_pred, y_pred, t_batch)
        Ux = autograd.grad(U_pred.sum(), x_pred, create_graph=True)[0]
        Uy = autograd.grad(U_pred.sum(), y_pred, create_graph=True)[0]
        loss_chem = ((dx_dt - Ux)**2 + (dy_dt - Uy)**2).mean()
        # Total loss
        loss = loss_data + 0.1*loss_geo + 1.0*loss_chem
        loss.backward()
        optimizer.step()
        epoch_loss += loss.item()
    scheduler.step()
    if epoch % 100 == 0:
        print(f"Epoch {epoch}: Loss = {epoch_loss/len(train_loader):.6f}")
        # Optional: visualize predicted vs true paths
        if epoch % 500 == 0:
            t_vis = torch.linspace(0, t_data.max(), 200).view(-1,1).to(device)
            with torch.no_grad():
                xy_vis = path_net(t_vis).cpu().numpy()
            plt.figure(figsize=(4,4))
            plt.plot(x_data, y_data, 'k.', label='True')
            plt.plot(xy_vis[:,0], xy_vis[:,1], 'r-', label='Pred')
            plt.legend(); plt.title(f'Epoch {epoch}')
            plt.show()
```

This notebook code demonstrates data loading, model setup, and a training loop with loss computation and periodic visualization. Adjust batch sizes and epochs based on dataset size and GPU memory. Training on a 16 GB GPU should allow moderate batch sizes (e.g. 64) and networks of this scale. For real week-long video data, consider downsampling or using subsequences.

## Step 5: API and Demo

We package the model into a user-friendly API. Create a Python module `cell_path_pinns.py` exposing a `predict_paths()` function:

```python
# cell_path_pinns.py
import torch

class CellPathModel:
    def __init__(self, path_state_dict, potential_state_dict, device='cpu'):
        """
        Initialize with pre-trained model weights.
        """
        self.device = torch.device(device)
        self.path_net = PathNet(hidden_dim=64).to(self.device)
        self.potential_net = PotentialNet(hidden_dim=64).to(self.device)
        self.path_net.load_state_dict(torch.load(path_state_dict, map_location=self.device))
        self.potential_net.load_state_dict(torch.load(potential_state_dict, map_location=self.device))
        self.path_net.eval()
        self.potential_net.eval()
    
    def predict_paths(self, t_sequence):
        """
        Forecast microbe positions given sequence of times.
        t_sequence: array-like of time points.
        Returns: numpy array of shape (len(t), 2) with (x,y) positions.
        """
        t_tensor = torch.tensor(t_sequence, dtype=torch.float32).view(-1,1).to(self.device)
        with torch.no_grad():
            xy_pred = self.path_net(t_tensor).cpu().numpy()
        return xy_pred

# For completeness, also provide function for batch predictions
def predict_paths(model, init_positions, times):
    """
    Example: ignore init_positions for this PINN, since it parameterizes absolute path.
    Returns predicted (x,y) for given times using model.
    """
    return model.predict_paths(times)
```

## Step 6: Validation Protocol

We validate forecasting accuracy and topology using temporal k-fold splits.

**K-Fold Temporal Split:** Divide each trajectory’s time span into *k* contiguous segments. For fold *i*, use segments ≠ *i* for training and segment *i* for testing (future prediction). This respects temporal order (no leakage). For each test segment, forecast from the last training point forward.

```python
import numpy as np
from sklearn.model_selection import TimeSeriesSplit
import matplotlib.pyplot as plt

def compute_displacement_error(true, pred):
    """Compute mean Euclidean displacement error between true and predicted trajectories."""
    return np.mean(np.linalg.norm(true - pred, axis=1))

def discrete_frechet(P, Q):
    """Compute discrete Frechet distance between curves P and Q (both shape (N,2))."""
    ca = np.full((len(P), len(Q)), -1.0)
    def c(i,j):
        if ca[i,j] > -0:
            return ca[i,j]
        d = np.linalg.norm(P[i] - Q[j])
        if i == 0 and j == 0:
            ca[i,j] = d
        elif i > 0 and j == 0:
            ca[i,j] = max(c(i-1,0), d)
        elif i == 0 and j > 0:
            ca[i,j] = max(c(0,j-1), d)
        else:
            ca[i,j] = max(min(c(i-1,j), c(i-1,j-1), c(i,j-1)), d)
        return ca[i,j]
    return c(len(P)-1, len(Q)-1)

# Example: Load a single microbe's trajectory (time-ordered)
times = np.linspace(0, 100, 1001)   # 0 to 100 sec
true_xy = np.vstack((np.sin(times/10), np.cos(times/10))).T  # example circular path
tscv = TimeSeriesSplit(n_splits=5)
errors = []
frechets = []

for train_idx, test_idx in tscv.split(times):
    t_train, t_test = times[train_idx], times[test_idx]
    xy_train, xy_test = true_xy[train_idx], true_xy[test_idx]
    # Train model on (t_train, xy_train) using Step 4 procedure...
    # For demonstration, assume model is retrained here (omitted)
    # Predict on test times
    pred_xy = model.predict_paths(t_test)  # using the API
    # Align lengths if needed (here same length)
    de = compute_displacement_error(xy_test, pred_xy)
    fe = discrete_frechet(xy_test, pred_xy)
    errors.append(de); frechets.append(fe)

print("Mean displacement error across folds:", np.mean(errors))
print("Mean Frechet distance across folds:", np.mean(frechets))

# Visualization for one fold
plt.plot(xy_test[:,0], xy_test[:,1], 'k--', label='True')
plt.plot(pred_xy[:,0], pred_xy[:,1], 'r-', label='Predicted')
plt.title('Trajectory Forecast (Test Fold)')
plt.legend(); plt.xlabel('x'); plt.ylabel('y')
plt.show()
```

This script demonstrates k-fold splitting (here `TimeSeriesSplit`) for one trajectory. For each test segment, it computes:

- **Displacement Error:** Mean Euclidean distance between predicted and true points.
- **Frechet Distance:** A topology-aware measure of curve similarity, capturing maximum deviation along the path【38†L167-L173】.

Visualizations include plotting true vs predicted path for qualitative assessment.
