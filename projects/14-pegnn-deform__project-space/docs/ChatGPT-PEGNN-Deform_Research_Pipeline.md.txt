## Step 1: Survey of GNN/FEM Surrogate Models (2020–2025)

We surveyed recent literature on graph neural network (GNN) surrogate models for physics simulation. Key works include **MeshGraphNets** (Pfaff *et al.*, ICLR 2021) which introduced a mesh-based GNN simulator that passes messages on an adaptive mesh graph and predicts dynamics orders-of-magnitude faster than traditional solvers【6†L19-L27】. **PhysGNN** (Salehi & Giannacopoulos, NeurIPS 2022) leverages GNNs to approximate finite-element soft-tissue deformation, explicitly using mesh connectivity for accuracy【13†L65-L73】. Extensions include **Physics-Encoded GNNs** (Saleh *et al.*, arXiv 2024) which integrate both soft and rigid bodies into graph structures and use cross-attention to model contact interactions【10†L61-L68】. **X-MeshGraphNet** (Nabian *et al.*, arXiv 2024) scales MeshGraphNet via graph partitioning and multi-scale point-cloud graphs, removing the need for mesh generation at inference【25†L61-L70】【25†L72-L77】. **Physics-informed MeshGraphNets (PI-MGNs)** (Würth *et al.*, CMAME 2024) hybridize GNNs with physics-informed losses to solve time-dependent PDEs on arbitrary meshes without large training sets【26†L63-L72】.

Surrogate models have also emerged in fluids and particle systems. For example, **GNS** (Kumar & Vantassel, arXiv 2022) is a generalizable graph network for particulate and fluid flow, incorporating physical inductive biases (e.g. inertial frame) and achieving \~5000× speedup over MPM baselines【20†L66-L74】. **NeuralMPM** (Rochman-Sharabi *et al.*, arXiv 2024) emulates the Material-Point Method via an image-based neural mapping, yielding multi-material fluid-solid interactions at hundreds of FPS with far lower memory than traditional MPM【17†L66-L74】. **GraphSplineNets** (Hua *et al.*, NeurIPS 2023) use spline collocation on coarse graphs to accelerate PDE forecasts, improving accuracy-speed tradeoffs for heat, wave, and Navier–Stokes equations【22†L25-L33】. Biomedical applications include a PhysGNN adaptation for breast compression simulation (Awwad *et al.*, MICCAI 2024), showing GNNs can learn surgical-tissue deformations with FEA-level accuracy.

**Limitations and Gaps:** Despite advances, existing models often require large training datasets (FEM simulations) and may not conserve physics over long horizons, leading to drift. Many focus on fluids or structured domains, with less work on complex deformable solids and real-time animation. Scalability to large meshes and integration with standard tools remain challenges. MeshGraphNets require remeshing and fixed topology, hindering flexibility. Real-time graphics applications demand strict stability (energy conservation) and interactions (contacts, collisions) that few models fully address. *Physics-encoded* GNNs partially fill this gap by embedding laws (e.g. Hooke’s law) into architecture, but further research is needed on robust, general GNN frameworks that replace FEM in production pipelines.

```python
# simulate_blender.py: Blender Soft Body simulation script
import bpy, bmesh, csv, mathutils

# Create a subdivided plane as deformable mesh (~1000-10k vertices)
bpy.ops.mesh.primitive_plane_add(size=2.0)
obj = bpy.context.object
mod = obj.modifiers.new(name="Subsurf", type='SUBSURF')
mod.levels = 5  # increase subdivisions (~2048 verts)
bpy.ops.object.modifier_apply(modifier=mod.name)

# Enable soft-body physics on the mesh
obj.modifiers.new("SoftBody", type='SOFT_BODY')
sb = obj.modifiers["SoftBody"].settings
sb.goal_friction = 5.0
sb.goal_default = 0.0  # free vertices (no pinned)
sb.use_goal = False
sb.mass = 0.3
# Optional: define structural stiffness (edge springs)
sb.pull = 0.0
sb.push = 0.0

scene = bpy.context.scene
scene.frame_start = 1
scene.frame_end = 100
scene.gravity = (0, 0, -9.81)

# Prepare CSV writer
def write_forces(frame):
    # Compute per-vertex forces: here approximate as mass * acceleration
    obj_eval = obj.evaluated_get(bpy.context.evaluated_depsgraph_get())
    mesh = obj_eval.to_mesh()
    forces = []
    for v in mesh.vertices:
        # Approximate force = mass * (current_vel - prev_vel) / dt (simple finite diff)
        # Blender API doesn't expose forces directly; this is a placeholder.
        forces.append((v.co.x, v.co.y, v.co.z, 0.0, 0.0, 0.0))
    obj_eval.to_mesh_clear()
    # Write to CSV
    with open(f"frame_{frame:03d}_forces.csv", 'w', newline='') as f:
        writer = csv.writer(f)
        writer.writerow(['vx','vy','vz','fx','fy','fz'])
        writer.writerows(forces)

    # Export geometry as OBJ
    bpy.ops.export_scene.obj(filepath=f"frame_{frame:03d}.obj", use_selection=True)

# Run the simulation and record data
for frame in range(scene.frame_start, scene.frame_end + 1):
    scene.frame_set(frame)
    # Allow evaluation of physics (in real use, use a frame-change handler or baked cache)
    write_forces(frame)

print("Blender simulation complete.")
```

## Step 3: Geometry Feature Extraction Module

Below is a Python module using PyTorch and PyTorch Geometric (PyG) to compute node/edge features on a mesh graph. It computes **Laplacian coordinates**, **cotangent edge weights**, and **principal curvatures** for each vertex. The functions take vertex positions and face indices as input and return tensors suitable for GNN input. Comments explain each part.

```python
# mesh_features.py
import torch
from torch_geometric.utils import degree

def compute_mesh_features(pos, faces):
    """
    Compute per-vertex and per-edge geometric features for a 3D mesh.
    
    Args:
        pos (Tensor[N,3]): Vertex coordinates.
        faces (LongTensor[F,3]): Triangle indices (0-indexed).
        
    Returns:
        node_features (Tensor[N,?]): Concatenated node features (e.g., Laplacian coords, curvatures).
        edge_index (LongTensor[2, E]): Directed edge indices for PyG graph.
        edge_attr (Tensor[E, d]): Edge features (e.g., cotangent weights).
    """
    N = pos.size(0)
    device = pos.device
    
    # Build adjacency and accumulate per-face cotangents
    neighbors = [[] for _ in range(N)]
    angle_sums = torch.zeros(N, device=device)
    one_ring_area = torch.zeros(N, device=device)
    cot_sum = {}  # accumulate cotangent for each undirected edge
    
    # Iterate faces to compute angles and cotangents
    for face in faces:
        i, j, k = face.tolist()
        # Vertex coordinates
        pi, pj, pk = pos[i], pos[j], pos[k]
        # Compute vectors for angle calculation
        def angle_at(a, b, c):
            u = pos[b] - pos[a]
            v = pos[c] - pos[a]
            cos_val = (u * v).sum()
            sin_val = torch.norm(torch.cross(u, v))
            return torch.atan2(sin_val, cos_val)
        angle_i = angle_at(i, j, k)
        angle_j = angle_at(j, k, i)
        angle_k = angle_at(k, i, j)
        angle_sums[i] += angle_i
        angle_sums[j] += angle_j
        angle_sums[k] += angle_k
        # Add neighbors (undirected)
        neighbors[i] += [j, k]
        neighbors[j] += [i, k]
        neighbors[k] += [i, j]
        # Compute triangle area for area around vertices
        tri_area = torch.norm(torch.cross(pj - pi, pk - pi)) * 0.5
        one_ring_area[i] += tri_area / 3.0
        one_ring_area[j] += tri_area / 3.0
        one_ring_area[k] += tri_area / 3.0
        # Cotangent for edges: cot(θ) = dot(u,v)/||u×v||
        def cotangent(a, b, c):
            u = pos[b] - pos[a]
            v = pos[c] - pos[a]
            sin_val = torch.norm(torch.cross(u, v))
            cos_val = (u * v).sum()
            return cos_val / (sin_val + 1e-8)
        cot_i = cotangent(j, k, i)  # opposite angle at i
        cot_j = cotangent(k, i, j)
        cot_k = cotangent(i, j, k)
        # Add to edges (undirected keys)
        for (a, b, cot_val) in [(j, k, cot_i), (i, k, cot_j), (i, j, cot_k)]:
            if a > b:
                key = (b, a)
            else:
                key = (a, b)
            cot_sum[key] = cot_sum.get(key, 0.0) + cot_val.item()
    # Unique neighbors list
    neighbors = [list(set(ng)) for ng in neighbors]
    
    # 1) Laplacian coordinates (node feature): pos - average(neighbors)
    L_coords = torch.zeros_like(pos)
    for i in range(N):
        neigh = neighbors[i]
        if len(neigh) > 0:
            L_coords[i] = pos[i] - pos[neigh].mean(dim=0)
    
    # 2) Construct edge_index and edge attributes (cotangent weights)
    edge_list = []
    edge_weights = []
    for (i, j), cot_val in cot_sum.items():
        # Add both directions for PyG
        edge_list.append((i, j))
        edge_list.append((j, i))
        edge_weights.append(cot_val)
        edge_weights.append(cot_val)
    if len(edge_list) > 0:
        edge_index = torch.tensor(edge_list, dtype=torch.long).t().contiguous()
        edge_attr = torch.tensor(edge_weights, dtype=torch.float).unsqueeze(1)  # [E,1]
    else:
        edge_index = torch.empty((2,0), dtype=torch.long)
        edge_attr = torch.empty((0,1), dtype=torch.float)
    
    # 3) Principal curvatures (node feature):
    # We approximate principal curvatures (k1,k2) from mean (H) and Gaussian (K) curvature.
    H = torch.zeros(N, device=device)
    K = torch.zeros(N, device=device)
    for i in range(N):
        area = one_ring_area[i]
        if area <= 0: 
            continue
        # Gaussian curvature: angle defect / area
        K[i] = (2*torch.pi - angle_sums[i]) / (area + 1e-8)
        # Mean curvature H: (1/(4A)) * sum_{neighbors j} (cot_ij + cot_ji)*(pos[i]-pos[j]) • N
        # Simplify: use magnitude formula: H = ||sum(cot*(pos_i - pos_j))||/(4A)
        Hvec = torch.zeros(3, device=device)
        for j in neighbors[i]:
            key = (i,j) if i < j else (j,i)
            cot_ij = cot_sum.get(key, 0.0)
            diff = pos[i] - pos[j]
            Hvec += cot_ij * diff
        H[i] = torch.norm(Hvec) / (4 * area + 1e-8)
    # Principal curvatures k1,k2 from H,K: H = (k1+k2)/2, K = k1*k2
    # Solve k1, k2 = H ± sqrt(H^2 - K)
    disc = (H**2 - K).clamp(min=0)
    k1 = H + torch.sqrt(disc)
    k2 = H - torch.sqrt(disc)
    curvature_feats = torch.stack([k1, k2], dim=1)  # [N,2]
    
    # Combine node features: [Laplacian coords (3), principal curvatures (2)] -> [N,5]
    node_features = torch.cat([L_coords, curvature_feats], dim=1)
    
    return node_features, edge_index, edge_attr

# Example usage:
# pos = torch.randn(1000,3)        # vertex positions
# faces = torch.randint(0,1000,(2000,3))
# node_feats, edge_idx, edge_attr = compute_mesh_features(pos, faces)
```

**Comments:** The Laplacian coordinate *L<sub>i</sub>* captures local geometry by subtracting the mean of neighbors. Cotangent weights are commonly used for discrete Laplace–Beltrami operators and mass-spring models. Principal curvatures are approximated from discrete curvatures (angle deficit *K* and mean curvature *H*) under the assumption of locally uniform area. In practice, specialized libraries (e.g. PyIGL, PyMesh) can compute curvatures more robustly; here we show a basic approach for integration into PyG.

## Step 4: PEGNN-Deform Model Architecture

We define a PyTorch + PyG model that encodes spring-mass physics and temporal dynamics. The architecture includes:

- **Message-passing layers:** Each edge models a spring (Hooke’s law). Edge features contain stiffness *k* and rest length *L₀*. The edge update computes spring force ∝ *k*(||xᵢ - xⱼ|| - L₀)·(unit vector). Messages are aggregated to form nodal forces.
- **GRU (Gated Recurrent Unit):** Updates hidden state per node over time, allowing the network to roll out many timesteps. At each step, the GRU takes the previous velocity (or force) and state to predict new velocity.
- **Mixed-precision:** We enable AMP (automatic mixed precision) for faster training/inference on supported GPUs.

```python
# pegdeform_model.py
import torch
from torch import nn
from torch_geometric.nn import MessagePassing
import torch.nn.functional as F

class SpringMessagePassing(MessagePassing):
    """
    Message passing layer for a spring network: computes spring forces on nodes.
    Edge_attr contains [stiffness, rest_length] per edge.
    """
    def __init__(self):
        super().__init__(aggr='add')  # sum aggregator
        # Optional edge MLP to modulate force
        self.edge_mlp = nn.Sequential(
            nn.Linear(2, 16), nn.ReLU(),
            nn.Linear(16, 1), nn.Sigmoid()
        )
    
    def forward(self, x, edge_index, edge_attr):
        # x: [N,3] node positions
        # edge_attr: [E,2] (stiffness k, rest length L0)
        return self.propagate(edge_index, x=x, edge_attr=edge_attr)
    
    def message(self, x_i, x_j, edge_attr):
        # Compute Hooke's law vector force from j->i
        diff = x_j - x_i           # [E,3]
        dist = torch.norm(diff, dim=1, keepdim=True)  # [E,1]
        k = edge_attr[:, 0].unsqueeze(1)             # stiffness
        L0 = edge_attr[:, 1].unsqueeze(1)            # rest length
        # Magnitude of spring force: k*(dist - L0)
        force_mag = k * (dist - L0)
        # Optional learnable modulation of force (e.g., damping)
        alpha = self.edge_mlp(edge_attr)  # [E,1]
        force_mag = force_mag * alpha
        # Direction: normalized diff (avoid zero div)
        direction = diff / (dist + 1e-6)
        force = force_mag * direction      # [E,3]
        return force

class PEGNNDeform(nn.Module):
    """
    Physics-Encoded GNN for deformable bodies. 
    Encodes springs via message passing and rolls out via a GRU.
    """
    def __init__(self, hidden_size=128):
        super().__init__()
        self.spring_mp = SpringMessagePassing()
        # Node feature embedding (optional)
        self.node_encoder = nn.Linear(3, hidden_size)
        # GRU for temporal velocity update
        self.gru = nn.GRU(input_size=3, hidden_size=3, batch_first=True)
        # Output MLP for velocity (if needed)
        self.vel_decoder = nn.Linear(3, 3)
    
    def forward(self, pos, vel, edge_index, edge_attr, hidden=None):
        """
        Inputs:
            pos: [N,3] current positions
            vel: [N,3] current velocities
            hidden: [1,N,3] GRU hidden state (optional)
        Returns:
            new_pos: [N,3], new_vel: [N,3], new_hidden
        """
        # Compute nodal forces from springs
        forces = self.spring_mp(pos, edge_index, edge_attr)  # [N,3]
        
        # Simple explicit integration: vel += dt * force; here dt=1 for simplicity
        pre_update = vel + forces
        
        # GRU update: incorporate previous velocity into hidden state
        # Reshape for GRU: [batch=1, N, features=3]
        gru_input = pre_update.unsqueeze(0)  # [1,N,3]
        if hidden is None:
            # Initialize hidden as zeros: [1, N, 3]
            hidden = torch.zeros(1, pos.size(0), 3, device=pos.device)
        gru_out, new_hidden = self.gru(gru_input, hidden)  # [1,N,3]
        new_vel = gru_out.squeeze(0)  # [N,3]
        
        # Update positions
        new_pos = pos + new_vel  # again dt=1 for simplicity
        
        return new_pos, new_vel, new_hidden

# Enable mixed precision in training/inference using AMP
# Example of usage:
# model = PEGNNDeform(hidden_size=128).cuda()
# with torch.cuda.amp.autocast():
#     new_pos, new_vel, hid = model(pos, vel, edge_index, edge_attr, hidden)
```

**Comments:** The `SpringMessagePassing` layer encodes Hooke’s law in its message function. The GRU is used for temporal roll-out: at each time step, the predicted velocity (combined spring forces and previous velocity) is passed through the GRU to produce a more stable update. We illustrate a simple integration (time step = 1); in practice include explicit time-step scaling. Mixed precision (`torch.cuda.amp`) is enabled to allow faster training on GPUs with limited memory.

## Step 5: Training Script and Loss

We define a PyTorch training script with a custom loss combining position MSE, velocity MSE, and energy-conservation penalties. The checkpoint saving is tailored for 24 GB GPUs by using smaller batches or gradient accumulation if needed.

```python
# train_pegdeform.py
import torch
import torch.nn as nn
from pegdeform_model import PEGNNDeform
from torch_geometric.loader import DataLoader
import numpy as np

# Set random seeds for reproducibility
seed = 42
torch.manual_seed(seed); torch.cuda.manual_seed_all(seed); np.random.seed(seed)

# Hyperparameters
learning_rate = 1e-4
batch_size = 4
num_epochs = 100
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Instantiate model, optimizer
model = PEGNNDeform(hidden_size=128).to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=learning_rate)

# Loss weights
lambda_vel = 0.1
lambda_energy = 1.0

# Training loop
for epoch in range(num_epochs):
    model.train()
    epoch_loss = 0.0
    for batch in DataLoader(train_dataset, batch_size=batch_size, shuffle=True):
        pos = batch.pos.to(device)          # [N,3]
        vel = batch.vel.to(device)          # [N,3]
        edge_index = batch.edge_index.to(device)
        edge_attr = batch.edge_attr.to(device)  # [E,2] stiffness,k0

        # Ground truth for next step
        pos_gt = batch.pos_next.to(device)
        vel_gt = batch.vel_next.to(device)

        # Forward pass
        with torch.cuda.amp.autocast():
            pos_pred, vel_pred, _ = model(pos, vel, edge_index, edge_attr)
        # Compute losses
        loss_pos = nn.functional.mse_loss(pos_pred, pos_gt)
        loss_vel = nn.functional.mse_loss(vel_pred, vel_gt)
        # Energy penalty: enforce spring+kinetic energy conservation
        # Compute predicted spring energy: sum(0.5*k*(||dx||-L0)^2)
        i, j = edge_index[0], edge_index[1]
        diff_pred = pos_pred[i] - pos_pred[j]
        d_pred = torch.norm(diff_pred, dim=1, keepdim=True)
        k_vals = edge_attr[:, 0].unsqueeze(1)
        L0_vals = edge_attr[:, 1].unsqueeze(1)
        spring_energy_pred = 0.5 * k_vals * (d_pred - L0_vals)**2
        kin_energy_pred = 0.5 * torch.sum(vel_pred**2, dim=1, keepdim=True)
        energy_pred = spring_energy_pred.sum() + kin_energy_pred.sum()
        # Ground truth energy (from pos, vel)
        diff_gt = pos_gt[i] - pos_gt[j]
        d_gt = torch.norm(diff_gt, dim=1, keepdim=True)
        spring_energy_gt = 0.5 * k_vals * (d_gt - L0_vals)**2
        kin_energy_gt = 0.5 * torch.sum(vel_gt**2, dim=1, keepdim=True)
        energy_gt = spring_energy_gt.sum() + kin_energy_gt.sum()
        loss_energy = (energy_pred - energy_gt).pow(2)

        loss = loss_pos + lambda_vel * loss_vel + lambda_energy * loss_energy
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        epoch_loss += loss.item()
    
    avg_loss = epoch_loss / len(train_dataset)
    print(f"Epoch {epoch}: Loss={avg_loss:.6f}")
    
    # Checkpoint schedule: save every 10 epochs
    if (epoch+1) % 10 == 0:
        torch.save({
            'epoch': epoch,
            'model_state': model.state_dict(),
            'optimizer_state': optimizer.state_dict()
        }, f'checkpoint_epoch_{epoch+1}.pth')
```

**Comments:** The training script expects a dataset providing `pos`, `vel`, and ground truth `pos_next`, `vel_next` for one-step prediction. We combine losses: position MSE, velocity MSE, and an energy mismatch penalty. The latter encourages the GNN to respect energy conservation (sum of spring potential and kinetic energy). We include a checkpoint schedule (every 10 epochs) that is safe for 24 GB GPUs; if needed, reduce `batch_size` or use gradient accumulation. We use mixed precision (`torch.cuda.amp.autocast()`) for efficiency. Ensure deterministic behavior by setting seeds (done above) and, if needed, `torch.use_deterministic_algorithms(True)`.

```python
for batch in DataLoader(test_dataset, batch_size=1):
    pos = batch.pos.to(device)
    vel = batch.vel.to(device)
    pos_gt = batch.pos_next.to(device)
    # Warm-up
    with torch.no_grad():
        _ = model(pos, vel, batch.edge_index.to(device), batch.edge_attr.to(device))
    # Measure latency
    start = time.time()
    with torch.no_grad():
        pos_pred, _, _ = model(pos, vel, batch.edge_index.to(device), batch.edge_attr.to(device))
    elapsed = time.time() - start
    latencies.append(elapsed)
    # Compute NRMSE: sqrt(mean((pos_pred - pos_gt)^2)) / (max-min of ground truth)
    mse = ((pos_pred - pos_gt)**2).mean().item()
    range_gt = (pos_gt.max() - pos_gt.min()).item()
    nrmse = (mse**0.5) / (range_gt + 1e-6)
    nrmses.append(nrmse)

print(f"Avg latency: {np.mean(latencies)*1000:.2f} ms")
print(f"Avg NRMSE: {np.mean(nrmses)*100:.2f}%")
```
